### Flagship projects

#### 📊 [FundLens](https://github.com/CALL-ME-TATA/FundLens) &nbsp;<img src="https://img.shields.io/badge/status-in%20progress-d29922?style=flat-square" alt="In progress" />
A mutual-fund portfolio tracker that turns raw **SIP, lump-sum and redemption** transactions into current value, absolute returns and **XIRR**.
- Relational **PostgreSQL** schema for users, funds, transactions and daily NAV history — `DECIMAL` precision, transactional writes
- **Scheduled job** ingests daily NAVs from a public mutual-fund API
- REST API on **Node.js + Express** with **JWT** auth; **React + Recharts** dashboard for value over time and allocation by category

`TypeScript` `Node.js` `Express` `PostgreSQL` `React` `Recharts` `JWT`

#### ⚡ [WattWise](https://github.com/CALL-ME-TATA/wattwise)
An **agentic AI system** that analyses and optimises power consumption across multiple data sources.
- Autonomous agents built on **Google ADK** for ingestion, **anomaly detection**, **forecasting** and automated reporting
- Time-series analysis of energy streams to flag abnormal consumption and surface optimisation insights
- **Async pipeline** for real-time analytics across diverse consumption profiles

`Python` `Google ADK` `LLM Agents` `REST APIs` `Time-Series`
